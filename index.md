# Operating Systems Coursework

* Module: Operating Systems
* Coursework: Technical Journal and System Demonstration
* Operating System: Ubuntu Server 24.04 LTS
* Virtualisation Platform: Oracle VirtualBox
* Workstation Environment: Windows + Git Bash
* Remote Administration Method: SSH

---

# Project Overview

This coursework documents the deployment, configuration, security hardening, monitoring, performance evaluation, and auditing of a Linux server operating system environment.

The project uses a headless Ubuntu Server virtual machine administered remotely from a Windows workstation through SSH command-line tools. The environment was designed to simulate professional Linux server administration practices used in enterprise and cloud infrastructure environments.

The coursework focuses on:

* Linux system administration
* SSH remote management
* Security hardening
* Firewall configuration
* Mandatory access control
* Intrusion detection
* Monitoring automation
* Performance analysis
* Security auditing
* Technical documentation

---

# System Architecture Summary

The infrastructure consists of:

* Windows Workstation Host
* Git Bash SSH Client
* Ubuntu Server 24.04 LTS Virtual Machine
* NAT Network Adapter
* Host-Only Adapter
* Oracle VirtualBox Hypervisor

The Ubuntu Server VM operates without a graphical interface and is administered entirely through SSH command-line access.
